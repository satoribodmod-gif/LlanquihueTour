# Llanquihue Tour

Prototipo en Java para representar personas vinculadas a la agencia turística.
El proyecto aplica clases, encapsulamiento, herencia, composición, validación de RUT y excepciones personalizadas.

## Estructura del proyecto

src/main/java/
- app/Main.java
- exception/RutInvalidoException.java
- model/Direccion.java
- model/Empleado.java
- model/Persona.java
- model/Rut.java

## Requisitos

-JDK 17
-IntelliJ IDEA

## Compilar y ejecutar

1 Abre el proyecto en IntelliJ IDEA.
2 Selecciona **Build --> Build Project** o presiona Ctrl+F9.
3 Abre src/main/java/app/Main.java.
4 Presiona la flecha verde junto al método main y selecciona **Run Main.main()**.
